## Why this exists

- Personal toolbox for daily development tasks.
- A safe place to learn about UI, state management, and data fetching.

## Getting Started

First install dependencies

```bash
pnpm i
```

Then, run the development server:
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment Variables

Set these in your local `.env.local` and in production:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

## Deployment Checklist

- `pnpm lint` passes
- `pnpm build` succeeds
